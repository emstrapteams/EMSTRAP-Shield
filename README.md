# EMSTRAP Shield

EMSTRAP Shield is a safety management application designed to manage employees,
facilities, safety equipment, inspections, emergency resources, training,
emergency drills, and safety reporting.

## Technology Stack

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- ExcelJS
- PDFKit

### Frontend
- React
- React Router
- Vite
